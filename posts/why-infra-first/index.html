为什么从 Infra 走到 Agent

Agent 的演示很快，一条慢轨迹我还拆不开。所以笔记从 GPU 写起，没写的阶段先空着。
2026-11-01 · 1 分钟 · chen.zhen

Agent 的演示我可以很快做出来。我现在做不到的是：拿一条慢轨迹，指出时间花在 prefill、decode、某次工具调用，还是上下文塞得太满。这个缺口就是笔记从 GPU 写起的原因。

六段不是分类标签，是成本往下传的关系。

  • Agent 多走一步，推理就多一次 decode，KV cache 就多占一块显存。
  • 推理能塞多大的 batch、多长的上下文，卡在 kernel 的访存和计算上。
  • 训练把同一套算子放大到多卡，多出来的是通信和显存怎么切。
  • 后训练决定进这个循环的模型会不会在任务上变好。它解释不了一次生成为什么要几十毫秒。

所以目录从 从 0 到 1 AI Infra 的计算与 GPU 开始。第一篇具体笔记是 CUDA 归约 kernel。那篇还没上 profiler。没测的部分留在文末，不补一个看起来完整的结论。
